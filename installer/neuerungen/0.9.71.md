## 0.9.71

Trendo OS auf USB-Stick oder externe SSD (Wunsch 04.11.2026):

- **Das Abbild kommt jetzt mit jedem Release:** GitHub baut bei jedem Release automatisch das bootfähige Trendo OS (Debian 13 mit KDE, deutsch). Es wird geprüft (UEFI- und BIOS-Start, Trendo-App, Sprache, Schutz für Windows und BitLocker) und mit Prüfsumme angehängt
- **Stick-Schreiber in der Einrichtung:** Bei „Auf einem USB-Stick“ oder „Auf einer externen SSD“ erkennt Trendo das Abbild im neuesten Release. Laufwerk wählen (ab 32 GB, die Windows-Festplatte erscheint nie), dann das Löschen bestätigen, indem du den Laufwerksbuchstaben eintippst. Trendo lädt das Abbild, prüft es, schreibt es nach der Rückfrage von Windows und liest am Ende alles zur Kontrolle zurück
- **Doppelter Schutz:** Vor dem Schreiben prüft Trendo noch einmal selbst, dass das Ziel weder Start- noch Systemlaufwerk ist, kein Windows enthält, extern angeschlossen und groß genug ist
- **Danach:** Trendo zeigt die Boot-Taste je Hersteller (z. B. Lenovo F12, HP F9, ASUS F8, MSI F11). Ohne Stick startet der PC wie immer Windows
- **Erster Start von Trendo OS:** Trendo OS fragt nach einem Passwort und legt damit auf dem restlichen Platz einen verschlüsselten Speicherbereich an. Dort bleiben Dateien, Programme und KI-Modelle erhalten. Angelegt wird er nur auf dem Laufwerk, von dem Trendo OS gerade läuft
