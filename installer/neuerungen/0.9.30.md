## 0.9.30

- **Claude direkt im Studio:** In jedem Studio öffnet „✳ Claude Code“ rechts im Fenster einen Claude-Bereich mit zwei Reitern:
  - „Claude Code“: dein echtes Claude Code läuft als Terminal im Projektordner – mit Rolle und Skills des Studios, „Auftrag senden“ übergibt den Text der Auftragsleiste, bleibt beim Weiterarbeiten im Studio offen
  - „Claude“: claude.ai mit deinem Abo direkt in Trendo (Chat, Bilder, Recherche, Claude Code im Web); du meldest dich einmal selbst an, Trendo merkt sich die Anmeldung; „Auftrag einfügen“ schreibt deinen Auftrag ins Eingabefeld
  - Ohne Installation oder Anmeldung zeigt der Bereich den nächsten Schritt („Claude Code einrichten“, „Mit dem Abo anmelden“); kostenpflichtige API-Schlüssel nutzt Trendo nie
