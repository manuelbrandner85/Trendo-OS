# Vorbild-Analyse Trendo Tabelle: Microsoft Excel, LibreOffice Calc (Clean-Room)

- Programme: „Trendo Tabelle“
- Vorbilder: Microsoft Excel, LibreOffice Calc, Google Tabellen
- Werkzeug: Funktionsumfang aus öffentlicher Doku und Bedienkonzept; kein fremder Code, keine fremden Grafiken oder Texte. Trendo-Stand aus dem Programmkatalog (Werkzeuge der Oberfläche) und dem Code, Stand 0.9.56 (F3 Texte & Tabellen).

## Funktionen eines Profi-Programms – Stand in Trendo
✓ vorhanden · ◐ teilweise · ✗ fehlt

- ✓ Menüband (Start, Einfügen, Daten, Überprüfen, Ansicht)
- ✓ Formeln: SUMME, MITTELWERT, WENN, SVERWEIS, SUMMEWENN, RUNDEN, HEUTE …
- ✓ Formatierung: fett, Rahmen, Füllfarbe, Euro, Prozent
- ✓ Bedingte Formatierung (Datenbalken, Farbskala, Regeln)
- ✓ Als Tabelle formatieren, sortieren
- ✓ Diagramme
- ✓ Datenüberprüfung (Auswahlliste), Notizen
- ◐ Mehrere Blätter (Reiter vorhanden, Verweise zwischen Blättern eingeschränkt)
- ✓ Pivot-Tabellen (Zeilen-, Spalten- und Wertefeld; Summe, Anzahl, Mittelwert) auf neuem Blatt – als Formeln, rechnen mit
- ✓ Fenster fixieren (Zeilen/Spalten einfrieren)
- ✓ Autofilter je Spalte mit Werteliste und Anzahl, mehrere Spalten zusammen (bleibt beim Speichern nicht erhalten)

## Bedienkonzept (Profi-Bauplan A1–A3)
Menüband + Raster + Formelleiste – Bauplan erfüllt.
