# Vorbild-Analyse CNC: CAMotics, NC Viewer, bCNC (Clean-Room)

- Recherche: CAMotics (GPL, Simulation von Fräsprogrammen), NC Viewer (Web-Vorschau von G-Code), bCNC (GRBL-Steuerung mit Editor)
- Werkzeug: Funktionsumfang aus öffentlicher Doku; kein Download, kein Code übernommen. REA nicht eingesetzt (kein lokal installiertes Vorbild).

## Übernommen in Trendo „CNC-Werkstatt“ (0.9.28)
Editor neben Vorschau, Werkzeugweg 2D/3D mit Eilgang-Unterscheidung, Simulation mit Zeitregler und aktueller Zeile, Prüfung (Vorschub fehlt, Eilgang ins Material, Arbeitsraum), Laufzeitschätzung, einfache Generatoren, Nullpunktverschiebung.

## Noch nicht
Materialabtrag-Simulation (Voxel), Werkzeugtabelle mit Längen, Steuerung einer echten Maschine (bewusst nicht – Realwelt-Aktor, nur mit eigener Freigabe), DXF/SVG zu G-Code.
