- Werkzeug: Funktionsumfang aus öffentlicher Doku und Bedienkonzept; kein fremder Code, keine fremden Grafiken oder Texte. Trendo-Stand aus Code und Tests, Stand 04.11.2026.

## Funktionen eines Profi-Programms – Stand in Trendo
✓ vorhanden · ◐ teilweise · ✗ fehlt

- ✓ Grundkörper, Skizze extrudieren, Drehteil
- ✓ Bohrung, Tasche, Rundung, Fase, Muster, Spiegeln, Verschieben, Drehen
- ✓ Normbohrungen M2–M12: Durchgang (ISO 273), Gewinde-Kernloch, Senkschraube (DIN 74) – wie das Bohrungswerkzeug in Fusion/Onshape
- ✓ Parametrisch: benannte Maße, Formeln in jedem Feld, Änderung rechnet alles neu
- ✓ Verlaufsbaum (Schritte, ein/aus, Reihenfolge), Rückgängig
- ✓ Mehrere Teile mit Lage und Farbe
- ✓ Eigenschaften: Volumen, Oberfläche, Masse je Werkstoff (Stahl, Aluminium, Holz, PLA …), Schwerpunkt (Fusion „Eigenschaften“)
- ✓ Querschnittsfläche in einer Höhe, Löcher abgezogen (Fusion „Querschnittsanalyse“)
- ✓ Technische Zeichnung als PDF: Vorder-, Drauf-, Seitenansicht, Schrägbild, Hauptmaße, Schriftfeld (FreeCAD TechDraw)
- ✓ Export STL, 3MF mit Farben, STEP (facettiert); direkt an den 3D-Druck
- ◐ Baugruppen: Teile mit Lage, aber ohne Verbindungen/Gelenke
- ✗ Skizzen mit Bedingungen (parallel, tangential, Maß gebunden)
- ✗ Echte BREP-Flächen (STEP ist facettiert)
