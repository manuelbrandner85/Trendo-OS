# STUDIO-LETTER-01 – Briefstudio-Oberfläche mit Akten
Reiter (eine Unterebene): Schnell schreiben · Akten · Akte · Prüfen & Ausgabe · Briefköpfe. Akte: Verfahrensart bestätigen, Rückfragen, Fakten (Tatsache/Vermutung/Frage), Chronik, Anlagen (Dateiauswahl, SHA-256), Eingangspost (Tesseract-OCR oder Text, Analyse, Anweisungen als Warnung), Termine suchen (UNGEPRÜFT), Bestätigen nur mit Quelle → .ics-Erinnerung, Rechtsquellen mit Nachschlagen + nur amtliche https-Quellen. Ausgabe: Ton, Prüfung + Korrekturlesen, Vorschau, DOCX/ODT/PDF mit Hash, Übersetzungsentwurf mit Vergleich und Faktenwächter, Versandweg, Gericht/Behörde-Klärung, Freigabe, Versand BLOCKED, Nachweis.
Briefe-Reiter aus Apps entfernt (sonst 3 Ebenen). Tests: UI-Komplettablauf + Reiter (App 50, Core 139).
