# Tabelle über den Auftrag

`tabelle.rechnen` rechnet Grundrechenarten und SUMME mit Decimal und schreibt die Zahlen in eine XLSX. Die Datei wird wieder gelesen. Teilen durch null bleibt ein Fehler ohne Datei. LibreOffice rechnet nicht nach.

Bild: `TRENDO_OFFICE_PROMPT=1 dotnet run --project tools/Trendo.Render -c Release -- tabelle-vorschau.png 1280 800 office`
