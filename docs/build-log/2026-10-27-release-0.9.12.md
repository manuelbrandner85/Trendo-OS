## Neu seit 0.9.11
- Handy verbinden Schritt für Schritt: jeder Schritt wird geprüft; QR-Code mit der echten WLAN-/LAN-Adresse (vorher teils Tailscale oder virtuelle Netzwerkkarte – Ursache für „kann nicht verbinden“); Hilfe nach 30 s mit Windows-Freigabe, anderer Adresse, neuem Code.
- Tailscale aus Trendo einrichten (offizielles Setup, Anmeldung, App aufs Handy); Unterwegs-Zugang per einmaligem Link.
- Trendo vom Handy bedienen (Bildschirm, Tippen, Schreiben, Tasten, Wischen) – nur nach Erlaubnis je Handy.
- Dauerhaft verbunden: Handy-Zugang startet mit Trendo, Schlüssel verlängert sich bei jedem Besuch, abgelaufener Code erneuert sich von selbst.
- Trendo als Handy-App: Startseite, alle Apps, Leiste unten, Programme in Handy-Breite auf einer eigenen Handy-Fläche, Handy-Tastatur und Auswahllisten, Zurück, ganzer PC-Bildschirm; zum Startbildschirm hinzufügbar.
- GitHub-Installation viel schneller: Programm wird über den Windows-Eintrag bzw. nur neue Ordner gefunden (vorher rekursive Suche durch ganz AppData).
- GitHub-Programme: Installer erkennen und still einrichten, sofort starten, Beschreibung aus der README; alles wieder entfernbar (GitHub-Programme, Quellcode, KI-Programme, Modelle, Laufzeiten).
