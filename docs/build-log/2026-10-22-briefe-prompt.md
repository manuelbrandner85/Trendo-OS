# Briefe über den Auftrag

`brief.schreiben` schreibt eine Word-Datei mit `Letters.WriteDocx`, liest sie zurück und legt die Felder daneben. PDF bleibt aus, solange LibreOffice fehlt. Der Stand ist „teilweise“.

Bild: `TRENDO_BRIEF_PROMPT=1 dotnet run --project tools/Trendo.Render -c Release -- briefe-vorschau.png 1280 800 brief`
