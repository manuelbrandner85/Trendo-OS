# 2026-10-22 – Live streamen

Studio „Live streamen“ nimmt Bildschirm, Fenster, Kamera und Mikrofon auf, zeigt eine Vorschau und speichert lokal. Eine Sendung ins Netz startet nur nach Freigabe, über FFmpeg (RTMP) oder OBS. Der Stream-Schlüssel steht nicht im Protokoll. Ohne Freigabe wird nichts gesendet.
