# LETTER-012 – Texterkennung auf Deutsch ohne Admin
PC hat Tesseract nur mit eng/osd. Trendo lädt deu.traineddata (tessdata_fast, Apache-2.0, 1,5 MB) in %APPDATA%\TrendoOS\tessdata, SHA-256 fest geprüft (19D219BB…), falscher Hash wird verworfen. Aufruf mit -c tessedit_create_tsv=1 (eigener tessdata-Ordner hat keine configs). Echter OCR-Test: gerenderter Brief → Texterkennung findet Kündigung/Stromvertrag/4711/München/31.12.2026, Sicherheit > 80 %.
