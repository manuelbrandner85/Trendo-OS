# 2026-10-22 3D-Auftrag

`modell.bauen` schreibt OBJ, MTL, Szenendatei und eine PNG-Vorschau aus `Mesh3D`. Die OBJ wird wieder eingelesen und die Breite geprüft. `modell.blender` startet Blender nicht und schreibt keine Blend-Datei.

Bild: `TRENDO_3D_PROMPT=1 dotnet run --project tools/Trendo.Render -c Release -- modell-vorschau.png 1536 1024 3d`
