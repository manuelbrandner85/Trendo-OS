# Verbesserung 43 – Studio-Erlebnis wie Claude Code + Profi-Webseiten
Freigegeben von Manuel am 22.10.2026 (alle 11 Punkte: JA). Ergänzt Verbesserung 42.
Leitlinie: so einfach wie möglich für Nutzer, aber hoch professionell. Lokale KI Standard, kein Bezahl-Abo nötig.

1. Live-Vorschau in jedem Studio (echtes Ergebnis neben der Eingabe; wo unmöglich, ehrlicher Hinweis).
2. Eingabefeld wie Claude Code: Plan zuerst, „Los“, sichtbarer Schritt-für-Schritt-Bau, gezielte Änderungen per Folgeeingabe.
3. Profi-Webseiten-Baukasten per Eingabe: jede Art von Webseite (Landing, Shop, Portfolio, Blog, Firma …).
4. Moderne Web-Techniken: immersives Story-Scrolling, Scroll-Animationen, Parallax, 3D im Browser (Three.js), Partikel/Shader, Video-Hintergründe, Mikro-Animationen.
5. Blender → Webseite: GLB aus 3D-Studio/Blender drehbar oder als Scroll-Animation.
6. Unreal → Webseite: gerenderte Videos/Bildsequenzen für Scroll-Effekte; Pixel Streaming nur auf ausdrücklichen Wunsch (braucht Server).
7. Stil-Vorlagen mit einem Klick (z. B. Apple-artig, verspielt, luxuriös, Tech), Schriften/Farben, alles änderbar.
8. Automatische Qualitätsprüfung jeder Webseite (Handy, Ladezeit, Barrierefreiheit, SEO-Grundlagen, Links) mit Note und „Jetzt beheben“.
9. Versionen und Rückgängig für jede Änderung.
10. Immer echte Datei/Ordner am Ende; Veröffentlichen nur nach ausdrücklicher Freigabe.
11. Einfach-Modus (Eingabe, Vorschau, Fertig) und aufklappbarer Profi-Modus (Code, Ebenen, Einstellungen).
