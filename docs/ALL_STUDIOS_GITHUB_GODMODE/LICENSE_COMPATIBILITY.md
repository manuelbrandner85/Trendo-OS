# Lizenzverträglichkeit
- Direkt einbaubar: MIT, BSD, Apache-2.0 (mit Vermerk in THIRD_PARTY.md).
- LGPL: nur als getrennter Prozess/dynamisch (z. B. MLT, FFmpeg).
- GPL: nur als externes Programm mit Dateiübergabe (Blender, Kdenlive, Audacity, QGIS).
- Ausgeschlossen: MeshLib (nicht-kommerziell), Tracktion Engine (GPL/kostenpflichtig) als Einbau.
