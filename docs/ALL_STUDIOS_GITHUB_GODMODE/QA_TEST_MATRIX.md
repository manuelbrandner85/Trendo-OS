# Testmatrix
Je Studio-Funktionspaket ≥10 Tests (positiv/negativ) – siehe studios/*/TEST_PLAN.md. Stand je Baustein: IMPLEMENTATION_STATUS.md; alles ohne Beleg ist NOT RUN.

Echtlauf-Tests (echte Fremdprogramme) finden ihre Programme automatisch (`tests/Trendo.Core.Tests/EchtWerkzeuge.cs`: Umgebungsvariable → TrendoWerkzeuge → Prüfordner); fehlt eins, übersprungen. Siehe reports/alle-studios/echtlauf-automatisch.md.
