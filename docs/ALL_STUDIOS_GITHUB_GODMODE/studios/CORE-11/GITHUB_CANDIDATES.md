# Kandidaten CORE-11
- restic/restic – AUSWAHL: BSD-2, Einzelprogramm: verschlüsselte, entdoppelte Sicherungen mit Versionen (z. B. auf USB-Platte), Prüfen und Wiederherstellen einzelner Dateien – offizieller Download mit fester Prüfsumme
- kopia/kopia – OPTION: Apache-2.0, ähnlich restic mit eigener Oberfläche – Option, eins von beiden genügt
- gitleaks/gitleaks – OPTION: MIT – Regelwerk für Geheimnisse (Schlüssel, Tokens) als Konzept/Daten für Trendos eigene Passwort-Suche
- keepassxreboot/keepassxc – EXTERN: GPL – Passwortmanager nur als externes Programm (KDBX-Datei bleibt bei der Person)
- borgbackup/borg – VERWORFEN: BSD-3, unter Windows nicht nativ – nicht übernommen
