# Kandidaten STUDIO-TV-01
- streamlink/streamlink – AUSWAHL: Python-Adapter (BSD-2): Live-Seiten öffentlich-rechtlicher Mediatheken in einen Abspielstrom wandeln – nur legale Quellen
- mpv-player/mpv – VORHANDEN: bereits integriert (externes Programm, GPL)
- iptv-org/iptv – AUSGESCHLOSSEN: Sammelliste mit ungeprüften Quellen – widerspricht „nur legale Quellen“; nicht übernommen
- jellyfin/jellyfin – ÜBERGABE: GPL-Medienserver, nur als externe Anbindung
- tvheadend/tvheadend – SPÄTER: für DVB-Hardware, Linux-lastig – später
