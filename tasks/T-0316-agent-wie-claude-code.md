## Ergänzung 01.11.2026 (Manuel): Claude-Abo so einfach wie möglich, Claude Code als Haupt-KI überall, wo programmiert wird
- Verbindung mit einem Knopf: Trendo findet `claude` (Benutzerordner `.local\bin`, npm, PATH), liest `claude auth status --json` (kostenlos; zeigt nur „angemeldet“, Anmeldeart und Abo-Stufe – E-Mail und Organisation werden weder angezeigt noch gespeichert). Nicht angemeldet → „Mit Claude verbinden“ startet `claude auth login --claudeai` (offizielle Anmeldung im Browser; Trendo sieht nie Passwort oder Schlüssel). Nicht installiert → offizieller Installer nur nach Zustimmung, ohne Admin.
- Wo programmiert wird (Web & App, App-Baukasten, Spiele, Programme nachbauen, Trendo erweitern, Abläufe/Skripte …) ist Claude Code die Haupt-KI, solange verbunden; sonst der Trendo-Agent mit lokaler KI. Kostenpflichtige KI bleibt optional (CLAUDE.md) – das Abo gehört dem Nutzer, Trendo setzt es nie voraus.
- Ablauf wie in Claude Code, sichtbar in Trendo: `claude -p … --output-format stream-json` im Projektordner. Zuerst Plan-Modus (`--permission-mode plan`) → Plan mit Ja/Nein → nach Ja Fortsetzen derselben Sitzung (`--resume`) mit `acceptEdits`; Aufgabenliste (TodoWrite) als Live-Checkliste, jede Datei-Änderung als Vorher/Nachher, Rückfragen beantwortbar, Stopp jederzeit, „alles rückgängig“ über eine Sicherung der geänderten Dateien.
- Grenzen: Arbeitsordner = Projektordner; Werkzeuge Read/Edit/Write/Glob/Grep/TodoWrite, Befehle (Bash) und Web nur nach eigener Zustimmung; Rolle und Skills des Programms per `--append-system-prompt`; Audit je Lauf.
