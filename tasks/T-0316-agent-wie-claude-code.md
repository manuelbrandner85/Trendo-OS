# T-0316 – Agent wie Claude Code für Web, Spiele und Code-Programme
- Freigabe: Manuel im Chat am 01.11.2026 – alle vier: Trendo-Agent wie Claude Code (lokale KI: Plan → Dateien lesen/ändern → Vorschau → Bildschirmfoto prüfen → nachbessern; jeder Schritt sichtbar, jede Änderung als Vorher/Nachher mit Ja/Nein, Rückfragen mit Knöpfen), echtes Claude Code nutzen, wenn installiert und angemeldet (Konto des Nutzers, nur nach Zustimmung, nie Pflicht), Rollen je Studio und Programm, ehrlicher Hinweis zur KI-Stärke (welches Modell arbeitet, Empfehlung für anspruchsvolle Designs).
- Grenzen: kostenpflichtige KI bleibt optional (CLAUDE.md); Dateizugriff des Agenten nur im Projektordner; keine Befehle außerhalb einer festen Liste ohne Zustimmung; Audit je Schritt.
- Baut auf: `WebsiteStudio`, `SoftwarePromptAdapter`, `GamePromptAdapter`, `WebsitePreview` (Bildschirmfoto), `IntelligenceCore`, T-0315 (Plan/Fragen/Vorschau-Oberfläche).

## Ergänzung 01.11.2026 (Manuel): Claude-Abo so einfach wie möglich, Claude Code als Haupt-KI überall, wo programmiert wird
- Verbindung mit einem Knopf: Trendo findet `claude` (Benutzerordner `.local\bin`, npm, PATH), liest `claude auth status --json` (kostenlos; zeigt nur „angemeldet“, Anmeldeart und Abo-Stufe – E-Mail und Organisation werden weder angezeigt noch gespeichert). Nicht angemeldet → „Mit Claude verbinden“ startet `claude auth login --claudeai` (offizielle Anmeldung im Browser; Trendo sieht nie Passwort oder Schlüssel). Nicht installiert → offizieller Installer nur nach Zustimmung, ohne Admin.
- Wo programmiert wird (Web & App, App-Baukasten, Spiele, Programme nachbauen, Trendo erweitern, Abläufe/Skripte …) ist Claude Code die Haupt-KI, solange verbunden; sonst der Trendo-Agent mit lokaler KI. Kostenpflichtige KI bleibt optional (CLAUDE.md) – das Abo gehört dem Nutzer, Trendo setzt es nie voraus.
- Ablauf wie in Claude Code, sichtbar in Trendo: `claude -p … --output-format stream-json` im Projektordner. Zuerst Plan-Modus (`--permission-mode plan`) → Plan mit Ja/Nein → nach Ja Fortsetzen derselben Sitzung (`--resume`) mit `acceptEdits`; Aufgabenliste (TodoWrite) als Live-Checkliste, jede Datei-Änderung als Vorher/Nachher, Rückfragen beantwortbar, Stopp jederzeit, „alles rückgängig“ über eine Sicherung der geänderten Dateien.
- Grenzen: Arbeitsordner = Projektordner; Werkzeuge Read/Edit/Write/Glob/Grep/TodoWrite, Befehle (Bash) und Web nur nach eigener Zustimmung; Rolle und Skills des Programms per `--append-system-prompt`; Audit je Lauf.

## Ergänzung 01.11.2026 (Manuel): volle Claude-Funktionalität, wenn Claude in Trendo verbunden ist
- Zwei Stufen je Projekt: „Sicher“ (Standard: `--restricted`, nur Dateien im Projektordner, keine Befehle, kein Web, keine fremden Erweiterungen) und „Volle Claude-Funktionen“ (einmal je Projekt mit Ja freigegeben, jederzeit widerrufbar): alle Werkzeuge von Claude Code – Befehle (Build/Test/npm), Websuche und Webseiten, eigene Skills/Plugins/MCP des Nutzers, Unteragenten, Bilder lesen; Rechte über Claude Codes eigenen Auto-Modus (`--permission-mode auto`) mit dessen Sicherheitsprüfung; Arbeitsordner bleibt das Projekt; Planphase ändert weiterhin nichts.
- Claude als Haupt-KI auch außerhalb der Code-Programme, solange verbunden (KI fragen, Recherche, Programm-Assistent, Studio-Aufträge); lokale KI bleibt Ersatz ohne Internet bzw. ohne Abo. Einstellung „Haupt-KI“: Claude (wenn verbunden) / lokal.

## Ergänzung 01.11.2026 (Manuel): Claude nur über das Abo, nie über die API
- Verbunden gilt nur eine Anmeldung über claude.ai (Abo) oder ein Abo-Token; Console-/API-Anmeldung wird als „nicht verbunden“ mit Erklärung angezeigt.
- Jeder Claude-Lauf entfernt Variablen, die auf die kostenpflichtige API umschalten würden (`ANTHROPIC_API_KEY`, `ANTHROPIC_AUTH_TOKEN`, `ANTHROPIC_BASE_URL`, Bedrock/Vertex/Foundry); Anmeldung nur mit `--claudeai`.
- Abo-Token (Idee von Manuel): „Token erzeugen …“ öffnet `claude setup-token`; der Token (sk-ant-oat…) wird im sicheren Windows-Speicher abgelegt und nur als `CLAUDE_CODE_OAUTH_TOKEN` an Claude Code gegeben. API-Schlüssel (sk-ant-api…) nimmt Trendo nicht an.
