# T-0616: Trendo OS einfacher bedienen (E1–E12)

**Freigabe:** alle 12 Vorschläge „Ja“ im Chat am 14.11.2026.
**Zweig:** `claude/T-0616-einfach-bedienen` (von `origin/main`)

Grundsatz: so einfach und verständlich wie möglich, ohne Nutzen oder Funktionen zu verlieren – nichts entfernen, nur bündeln, einklappen, automatisieren, verständlicher benennen. Alles bleibt erreichbar (Menü „Mehr“, Hinweis, Einstellungen, Stufe Erweitert/Profi).

| Nr. | Vorschlag |
|---|---|
| E1 | Ein KI-Knopf „KI ▾“ in der KI-Leiste (Claude, kie.ai, Markierung an Claude, Weiter mit Projekt, Hinzufügen); kein doppeltes „Claude“ im Programmband |
| E2 | Stufe Einfach: Stufenwahl, Rand-Schalter und Eigenschaften eingeklappt, „Mehr Werkzeuge“ holt sie; Stufe auch im „Mehr“-Menü und in den Einstellungen |
| E3 | Automatisch speichern (neu im Studio-Ordner, danach bei jeder Änderung, entprellt), Anzeige nur „Gespeichert“, Versionen sichern frühere Stände, leere Dokumente legen keine Datei an |
| E4 | Öffnen und Speichern unter mit der Dateiauswahl des Systems (Test-Übersteuerung) |
| E5 | „Weitermachen“ öffnet das zuletzt bearbeitete Dokument (Desktop und oberste Karte der Startansicht) |
| E6 | „Was möchtest du machen?“ startet die Aufgabe direkt, fehlt eine Angabe, fragt Trendo kurz |
| E7 | Fehler mit „Was tun?“: Alltagssatz, ein Knopf, technischer Text aufklappbar; Kern-Zuordnung testbar in Trendo.Core |
| E8 | Kurze Einführung beim ersten Öffnen eines Programms (drei Schritte), überspringbar, über die Hilfe wieder abrufbar |
| E9 | Ein Schalter „Einfach / Erweitert / Profi“ statt „Einfacher Modus“ und „Bedienstufe“, alte Einstellungen werden umgerechnet |
| E10 | Alltagswörter in linker Leiste, Widgets, Einstellungen; Fachwort als Hinweis |
| E11 | Ein Suchfeld je Seite (Studio-Übersicht), Profi-„Befehle suchen“ in Strg+K, Hilfetext zu Strg+K korrigiert |
| E12 | Einfach: rechte Widget-Spalte, Erdkugel und Schnellaktionen ausgeblendet (einblendbar), Einstellungen mit Hauptseiten und „Mehr“ |

## Grenzen

- Nichts wird gesendet, gekauft oder veröffentlicht; „Claude fragen“ füllt nur die Eingabe, abgeschickt wird von der Person.
- Speichern überschreibt nie fremde Dateien (freier Name im Studio-Ordner, die Dateiauswahl fragt selbst nach).
- Registrier-Dateien der parallelen Studio-Aufträge (T-0614, T-0615) bleiben unberührt.
