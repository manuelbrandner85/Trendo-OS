# Präsentationen, die wirken

## Aufbau
- Ablauf: Problem → Lösung → Belege → nächster Schritt. Die erste Folie nennt das Ziel, die letzte den Auftrag ans Publikum.
- Eine Botschaft je Folie; die Überschrift ist die Aussage („Kosten sinken um 18 %“), nicht das Thema („Kosten“).
- Höchstens drei Punkte je Folie, je Punkt höchstens eine Zeile.

## Gestaltung
- Großer Text (Überschrift mindestens 32 pt, Text mindestens 20 pt), viel Raum, einheitliche Ränder.
- Diagramme statt Tabellen; die wichtige Zahl hervorheben, den Rest zurücknehmen.
- Bilder randabfallend oder klar gerahmt; keine Clipart, keine Effekte als Selbstzweck.
- Einheitliche Farben und Schriften aus der Vorlage; Foliennummer sichtbar.

## Checkliste
- Jede Überschrift ist eine Aussage
- Höchstens drei Punkte je Folie
- Text auch aus 5 m Entfernung lesbar
- Diagramme beschriftet, Kernzahl hervorgehoben
- Erste Folie nennt das Ziel, letzte den nächsten Schritt
- Einheitliche Farben, Schriften und Ränder
