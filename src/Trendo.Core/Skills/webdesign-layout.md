# Layout und Typografie

## Aufbau
- Vom Wichtigen zum Einzelnen: Hauptaussage oben, Belege in der Mitte, Handlungsaufforderung am Ende.
- Abstände stammen aus einer Skala in 4er- oder 8er-Schritten. Was zusammengehört, steht enger zusammen als das, was sich trennt.
- Fließtext bekommt 60 bis 75 Zeichen Zeilenlänge. Breite Bildschirme füllt man mit Rand, nicht mit längeren Zeilen.

## Schrift und Farbe
- Höchstens zwei Schriftfamilien, Grundgröße mindestens 16 px, Zeilenhöhe 1,5 bis 1,7 für Text.
- Größen folgen einer festen Stufung; eine Überschrift ist deutlich größer als die nächste Ebene.
- Eine Akzentfarbe für das, was geklickt werden soll, sonst ruhige Neutraltöne. Farbe trägt nie allein eine Bedeutung.

## Checkliste
- Eine klar erkennbare Hauptaussage je Abschnitt
- Abstände stammen aus einer einheitlichen Skala
- Höchstens zwei Schriftfamilien
- Grundschrift mindestens 16 px
- Genau eine Akzentfarbe für Bedienelemente
