# SEO

## Inhalt
- Der Text beantwortet, was Besucher suchen, in ihren Worten. Keine Aneinanderreihung von Suchbegriffen.
- Jede Seite hat ein eigenes Thema, genau eine Hauptüberschrift und sprechende Zwischenüberschriften.
- Bilder haben beschreibende Dateinamen und Alternativtexte.

## Angaben je Seite
- Seitentitel höchstens etwa 60 Zeichen, das Wichtigste vorn.
- Beschreibung etwa 120 bis 155 Zeichen, sagt konkret, was die Seite bietet.
- Verständliche Adressen, keine doppelten Inhalte, interne Links mit aussagekräftigem Text statt „hier klicken“.

## Checkliste
- Eigener Seitentitel unter etwa 60 Zeichen
- Beschreibung vorhanden und konkret
- Genau eine Hauptüberschrift
- Linktexte sagen, wohin es geht
- Keine kaputten internen Links
